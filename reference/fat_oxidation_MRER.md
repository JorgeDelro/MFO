# Calculate MFO using the MRER method (Perez-Martin et al.)

Calculate MFO using the MRER method (Perez-Martin et al.)

## Usage

``` r
fat_oxidation_MRER(VO2, RER)
```

## Arguments

- VO2:

  vector of oxygen consumption values (ml/min)

- RER:

  vector of respiratory exchange ratio values

## Value

fat oxidation rate in g/min
